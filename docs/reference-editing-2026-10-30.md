# 编辑工作区复刻记录（2026-10-30）

## 范围与参考

本次以用户给出的两张截图及 https://www.ilovepdf.com/zh-cn/edit-pdf 的实际编辑界面为参考。删除独立的“注释模式”，文档打开后直接进入“编辑文本 / 编辑内容”。编辑模式内部的“注释、形状、插入、编辑文本、表单”五个页签仍然保留，与用户截图一致。品牌保持 PDFX，所有 PDF 编辑在本机执行。

参考站通过浏览器实际打开合成 PDF，观察了编辑文本、添加段落、形状、样式、插入、表单、缩略图和窄屏状态。没有上传用户的个人文档，也没有复制参考产品的商业 SDK。图标使用本地打包的 Lucide（ISC 许可证）。

## 本轮追加的内容编辑交互

单击先选中、八向手柄、矩阵平移、宽度重排、原行距、双击输入及保存重开的最终验证与定版范围见 [定版记录](releases/2026-10-30.md)。

## 已实现与修正

- 48px 主工具栏、49px 图标工具行、白色左右侧栏、浅灰画布、底部深色页码/缩放栏、右下红色保存按钮。
- 左侧按钮正确切换导航侧栏，不再错误映射成删除注释。切换侧栏保持当前编辑工具。
- 编辑文本工具顺序为“添加段落、新图片、编辑内容”，默认激活编辑内容。未选择文字时显示禁用的文字样式；选中后可编辑字体、字号、粗体、斜体、下划线、删除线、对齐、颜色及文字区域链接。
- 自定义颜色保存在本机，可在不同页面和文档窗口中继续使用。
- 连续页视图，邻近页面才加载预览；滚动、缩略图、页码输入联动；缩略图大小可以调节。
- 文档大纲读取真实 PDF 目的地；书签为保存在本机的阅读书签；搜索读取本地文档文本并跳转到匹配页面。
- 保留已有矩形、椭圆、直线、箭头；补充弧、多边形、云形、折线。多边形和折线单击增加顶点，双击或 Enter 完成。
- 插入图章、签名、附件和图片印章；表单字段工具沿用真实 AcroForm 创建与填写能力。
- 修复工具切换中的过期回调，保证旧工具退出后再激活新工具。
- 文本草稿在保存与切页前提交，验证失败阻止保存；尚未提交的输入也显示未保存标记并参与关闭确认。
- 原文编辑框使用不透明背景与真实字体子集，空格度量、固定框宽和保存时的排版一致；重复空格在重开后保留。
- macOS 字体发现不再遍历 WPS 私有容器，避免系统隐私访问等待锁住整个编辑会话。仍读取系统字体、用户安装字体及 WPS 安装包字体；不分发商业字体。

## 仍与参考产品不同的行为

这不是 Apryse 商业编辑引擎的完整替代，不能宣称所有 PDF 和所有边缘交互都与参考站完全一致。

- 已支持相邻同字体、同样式多行的整体选择和框内重排。复杂混合字体、跨对象结构的自动分组仍与参考商业引擎不同；旋转文字和非常规排版继续受现有引擎边界限制。
- 弧、多边形、云形、折线通过原生 Ink 笔画保存，支持保存、撤销和擦除；没有完整复制参考站的多边形填充、虚线、云边细节及顶点二次编辑。
- 阅读书签仅保存在本机，不写入 PDF Outline；大纲本身只读。搜索按命中页面显示结果，目前不绘制逐字命中高亮。
- 工具图标采用独立的开源图标；原生字体选择器、文件选择器和保存选项遵循桌面系统界面。首次保存选择新文件，不覆盖源文档。
- 不包括账户、云存储、会员订阅、OCR 或数字证书签名。签名是已有的视觉签名/表单签名栏功能。
- 不再自动发现 WPS 私有容器中下载的字体；需要使用此类字体时，先通过系统字体管理安装。
