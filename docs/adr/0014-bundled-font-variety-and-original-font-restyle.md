# 字体列表内置八款 OFL 字体，原字体默认只重排字号与颜色

用户要求编辑 PDF 文字时像 WPS 一样选择字体与字号。WPS 随附的宋体、黑体、楷体、微软雅黑、华文与方正字体均为商业授权，不满足 ADR-0006 的“只随包分发可自由嵌入字体”原则，因此 PDFX 选择八款 SIL OFL 1.1 字体作为可选的视觉近似：思源黑体（Noto Sans SC）、思源宋体（Noto Serif SC）、朱雀仿宋、霞鹜文楷（楷体近似）、得意黑、马善政毛笔楷书、站酷小薇、站酷庆科黄油。全部复用 ADR-0011 与 ADR-0013 的 CIDFontType2 + FontFile2 子集管线；出处、版本与 SHA-256 记录在 `src-tauri/fonts/SOURCE.txt`。代价是安装包增大约 47 MB，其中霞鹜文楷 25 MB，是最大的一笔。

“文本样式”面板把 PDF base-14 的 12 个变体与八款内置字族排在一起，字号输入支持 4–400 pt，并提供 8、9、10、10.5、11、12、14、16、18、20、22、24、26、28、32、36、42、48、56、64、72 的 WPS 风格常用字号。Noto 两款有字重轴，粗体作用于 700 字重；其余六款只有 Regular，粗体保持常规轮廓；八款都没有斜体，选择斜体会返回“不支持字体”，而不是静默丢弃。

编辑已有文字时，若原字体是任意嵌入字体且不在可选列表内（例如 FangS-SC、HYShuSongErKW），不改字族而只改字号或颜色会触发“原字体重排”：用原字体的字形重新生成文本对象，只替换字号与填充色，字体 token 保持原样。粗体、斜体、下划线与对齐不在此列，因为修改它们必须重新选择字体；面板会提示用户改选其他字体，选择后该文本框转换为 Styled Text Box。原字体无法保留时（未嵌入的任意字体、不在列表内的 base-14 PostScript 名），面板默认选择最接近的内置字族：仿宋类 → 朱雀仿宋，其他衬线 → 思源宋体，其余 → 思源黑体。

这延续 ADR-0012 的“按字符优先复用原字体”，并修正了此前“只要修改样式就把整段文字换成 Helvetica 或思源黑体”的行为。

后续：[ADR-0015](0015-installed-system-and-wps-fonts.md) 在回退链中插入“本机安装的同名字体”——当原字体未嵌入或缺少要写的字时，先使用用户机器上已有的同名字体（例如 WPS 的 FangS-SC），仍不可用时才使用这里列出的内置字族。内置字体列表本身不变。
