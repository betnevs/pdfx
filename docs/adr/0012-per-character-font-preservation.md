# 编辑文字时按字符保留原字体，缺字形时按风格回退

编辑已有文字时，替换文本不再整段换成同一个内置字体。每个替换字符先检查文档原嵌入字体能否绘制该字形：能绘制就继续使用原字体，只有缺字形的字符改用回退字体。回退字族按原字体名判断——仿宋名称使用随包内置的朱雀仿宋（见 [ADR-0013](0013-fangsong-fallback-face.md)），宋体、明体、楷体以及 Times/Georgia 等其余衬线名称使用 Noto Serif SC，非衬线名称使用 Noto Sans SC。因此中英文混排、只改几个字的场景不会把整段宋体文档变成黑体，也不会让仿宋文档里的新字明显变重。

这一决策取代 [ADR-0011](0011-initial-shipped-fonts.md) 中“初始版本只内置 Noto Sans SC”的限制：Noto Serif SC（OFL 1.1）已完成同一套 CIDFontType2 + FontFile2 子集管线与再分发许可复核，并加入包体。代价是应用体积增加约 24 MB（可变字重的 Noto Serif SC TTF）；写入 PDF 时仍只做子集嵌入，文档体积只随实际用到的字形增长。

回退判断必须在后端完成，因为只有后端能读取嵌入字体程序并用 `ttf-parser` 证明字形覆盖；前端不使用原始 PDF 字体名做 CSS 字体，而是映射到系统安装的近似字族只用于编辑框预览，避免预览时已显示成默认无衬线字体。
