# PDFX 0.1.0 定版记录（2026-10-30）

用户确认当前版本功能测试正常，冻结本轮实现。交付为 Apple Silicon macOS Release 构建，沿用项目的 ad-hoc 签名，未使用 Developer ID 签名或 Apple 公证。

## 定版范围

- 仅编辑模式、五个工具页签、连续页面、缩略图、大纲、本机书签与搜索。
- 单击选择，双击输入，八向控制点，移动及调整框宽；草稿在切换工具、切页和保存前提交。
- 原字体优先与按字符回退、八款 OFL 字体、本机/WPS 字体发现及许可证随包分发。
- 修正中文提交、空格宽度、重复空格重开、输入预览与保存框宽不一致，以及调整宽度后备用字形丢失。
- 默认适合宽度，Ctrl/Command + 滚轮缩放，渲染等待期间保留页面图，最近文件单条移除与全部清空。
- 普通文本移动缓存背景和透明字形，移动帧不调用原生渲染；松手一次提交。无法安全合成的页面回退原生预览。

同一测试文档的发行构建中，scale=2 的完整预览中位耗时由 70.9 ms 降为 37.7 ms；移动缓存一次准备为 15.2 ms。该数据是原生调用计时，不是屏幕 FPS。

## 验证

前端完整测试 742 项通过；原生完整测试 572 项通过、3 项既有手动测试跳过。TypeScript、Rust 格式及 Release 包校验通过。前端检查在并发编译阶段曾超时，编译结束后独立重跑全套通过。交付目录 `BUILD-INFO.txt` 记录产物与提交信息。既有实机验证已覆盖中文和 0/1/2 个空格的提交、保存重开、删减后再输入、调整框宽、移动、撤销、缩放及最近文件管理。

完整边界见 [已知限制](../known-limitations.md) 和 [编辑工作区记录](../reference-editing-2026-10-30.md)。本轮验收不代表任意复杂 PDF、混合字族分组或所有参考产品边缘行为完全一致。Windows 与 Intel macOS 未在本次进行实机验证。

## 交付与清理

- 本机交付目录为 `release/macos/`，保留正式 `.app`、`.dmg`、校验和及构建信息，不纳入 Git。
- 清理开发临时目录、调试应用、测试输出、旧构建缓存和重复截图/验收日志；保留源码、回归测试、字体许可、必要 ADR 及历史测试语料。
- 用户文档与应用数据不作为构建垃圾删除；定版前未保存内容的保护副本放在本机 `saved-documents/`（不纳入 Git）。
