- PDF 文件在 Windows checkout 时必须保留二进制原样，避免换行转换破坏 xref 偏移与内嵌流长度。
- Windows 备份文件刷盘需要可写句柄，修复重复保存的权限错误。
- TTC 字体集合不能作为单字体 sfnt 目录重排，修复已安装 SimSun 的子集生成。
- 移除第三方包装层将注释句柄强转为页面对象句柄的四条颜色访问回退，修复 Windows 访问越界崩溃；保留专门的外观/颜色/保存重开回归测试。
- 修正 Windows 专用断言的类型错误，并使字体、非法文件名和目录替换错误的测试遵循真实平台语义。

## 交付

普通用户使用 `PDFX_0.1.0_x64-setup.exe`。安装器内置 WebView2 离线组件，约 261 MiB，未配置 Authenticode 签名。

完整产物保留在构建的 `PDFX-windows-x64` Artifact 中。若只需安装器，可运行 **Prepare Windows installer download** 工作流，填入成功构建的 run ID；它验证已有产物后提供较小的 `PDFX-windows-installer`，不重新编译。Artifacts 默认保留 14 天，需要长期保留请下载归档。

本机保留安装器、SHA-256、安装说明和构建信息，位于 `release/windows/`，不纳入 Git。回归构建缓存和临时诊断日志已清理；Mac 正式应用未重建或覆盖。
