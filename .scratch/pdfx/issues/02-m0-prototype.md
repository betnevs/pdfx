# 02: M0 浏览器高保真原型

**What to build:** 一个浏览器里可评审的 PDFX 工作区原型，复刻 iLovePDF 编辑页的信息架构：顶部“注释/编辑”模式、五个页签、左侧缩略图栏、中央画布、右侧属性面板、底部页码/缩放条，全部中文文案，使用占位 PDF 内容。

**Blocked by:** 01 (Repo + Tauri/React 脚手架 + 测试与 fixture 骨架)

**Status:** ready-for-agent

- [ ] 1440×900 与 1280×720 下布局不溢出，面板可折叠/展开。
- [ ] 五个页签切换时右侧属性面板与画布工具状态同步。
- [ ] 缩略图点击跳转、页码输入、缩放百分比与“适合宽度/页面”可用。
- [ ] 选中文字/注释/形状时属性面板显示对应控件；占位内容足以演示三种状态。
- [ ] 所有用户可见文案为简体中文且集中管理，后续可加英文。
