# 38: 图层

**What to build:** 用户可以在图层面板查看 Page 的图层，切换可见性，重命名或删除可选图层；保存后图层状态保留。

**Blocked by:** 10 (Save As / Save Changes 管线)

**Status:** ready-for-agent

- [ ] 图层面板列出当前 Page 的 Optional Content Groups 与可见性状态。
- [ ] 切换可见性立即反映在画布；保存后状态保留。
- [ ] 可重命名图层；删除图层前有确认，并说明对内容的影响。
- [ ] 没有图层的 Document 显示空状态，不报错。
- [ ] 撤销/重做覆盖可见性与重命名操作。
