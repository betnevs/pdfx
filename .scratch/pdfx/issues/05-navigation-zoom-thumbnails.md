# 05: 翻页、缩放与缩略图

**What to build:** 用户可以在 Document 内翻页、跳转、缩放与全屏查看；左侧缩略图栏懒加载并可点击定位，底部显示当前页/总页数与缩放比例。

**Blocked by:** 04 (打开文档并渲染第一页)

**Status:** ready-for-agent

- [ ] 页码输入、上一页/下一页、Home/End 跳转正确。
- [ ] 10%–4000% 缩放、适合宽度、适合页面均可用；缩放后文本层与覆盖层对齐。
- [ ] 缩略图栏只渲染可见与邻近页，滚动长文档不阻塞；点击缩略图跳转到对应 Page。
- [ ] 全屏查看模式可进入/退出，退出后恢复原缩放与页码。
- [ ] 旋转页与混合页面尺寸显示正确，不出现裁剪或错位。
