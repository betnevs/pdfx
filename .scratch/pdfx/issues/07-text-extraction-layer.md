# 07: 文本提取与文本层

**What to build:** 每页渲染出与底图对齐的文本层，用户可以点击与选择文字；Scanned PDF 或没有文本层的 Page 显示“此页没有可编辑文字”的提示。

**Blocked by:** 04 (打开文档并渲染第一页)

**Status:** ready-for-agent

- [ ] 文本层字符位置与渲染底图对齐，缩放/旋转后仍对齐。
- [ ] 可以按字符、词、行选择文字；选择结果能驱动高亮与复制。
- [ ] 文本型、CJK、混排、CID/Type0 字体的 Page 都能提取到文字。
- [ ] Scanned PDF 不产生伪文本层，并显示不可编辑提示。
- [ ] 文本提取不阻塞翻页与缩放；大文档按页懒加载。
