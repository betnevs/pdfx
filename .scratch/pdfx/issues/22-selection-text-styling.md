# 22: 选区级混合文本样式

**What to build:** 用户可以在一个 Text Box 内选中部分文字，应用不同的字体、字号、颜色、粗体/斜体/下划线，形成混合样式并保存。

**Blocked by:** 09 (新增 Text Box 与样式), 11 (CJK 字体回退与子集嵌入)

**Status:** ready-for-agent

- [ ] 选区级样式修改只影响选中文字，不影响同框其他文字。
- [ ] 混合样式在画布、保存后 PDFium 提取与外部阅读器中一致。
- [ ] 字体切换时缺字形回退提示与整框模式一致。
- [ ] 撤销/重做按样式操作粒度工作。
- [ ] 不引入段落 reflow；行高与换行保持 Text Box 规则。
