# 36: 附件

**What to build:** 用户可以把文件作为附件插入 Document，查看附件列表，打开或另存附件；保存后附件随 PDF 一起保留。

**Blocked by:** 10 (Save As / Save Changes 管线)

**Status:** ready-for-agent

- [ ] 可选择本地文件插入为附件，显示文件名、大小与类型。
- [ ] 附件列表可打开/另存附件；删除附件有确认。
- [ ] 保存后在 Preview、Adobe Acrobat Reader、Chrome 中附件仍存在且可提取。
- [ ] 撤销/重做覆盖附件插入与删除。
